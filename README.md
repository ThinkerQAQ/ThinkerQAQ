## About Me

I'm a backend engineer interested in **distributed systems, software architecture, and developer infrastructure**.

My engineering experience spans backend services, API gateways, and distributed systems, primarily using **Go and Java**.

I enjoy exploring how software works beneath its abstractions — from concurrency and operating systems to distributed architectures and developer tooling.

Currently, I'm also exploring AI engineering and agent runtimes.

Outside of engineering, I enjoy photography, fitness, hiking, and reading.

## Engineering Philosophy

> Understand the problem → Identify the principles → Design the architecture → Validate in practice.

I believe in a few simple principles:

- **Simplicity** — Keep the core small and responsibilities clear.
- **Composability** — Build replaceable components with well-defined interfaces.
- **Pragmatism** — Reuse proven solutions before building new ones.
- **Understanding** — Understand the underlying mechanisms, not just the abstractions.
- **Validation** — Test ideas against real-world constraints.

## Featured Projects

### [Inkerio](https://github.com/ThinkerQAQ/ThinkerQAQ.github.io)

A bilingual static blog engine built with Astro, with content kept in a separate repository.

Its companion **BlogCTL** handles site assembly, multi-platform publishing, and search-engine submission. Start with the [Inkerio Content Template](https://github.com/ThinkerQAQ/inkerio-content-template) to build your own site.

My personal blog at [thinkerqaq.com](https://thinkerqaq.com/en/) runs on Inkerio.

### [DownKit](https://github.com/ThinkerQAQ/downkit)

A media downloader combining a browser extension with a local Go service.

Supports video and audio downloads, media processing, and optional subtitle-related workflows.
